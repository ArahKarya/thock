# Thock ⌨️

**Cross-platform mechanical keyboard sounds** — an open-source utility that
plays a satisfying click on every keystroke. Runs in the menu bar / system
tray on **macOS, Linux, and Windows**.

Built with [Tauri 2](https://tauri.app) (Rust backend + web UI).

> Thock is an original, clean-room project. It is **not** affiliated with, and
> contains **no** code or assets from, any other keyboard-sound application.
> All bundled sounds are procedurally synthesized (CC0). See
> [Licensing & provenance](#licensing--provenance).

## Features

- Global keystroke → sound, system-wide, with auto-repeat suppression
- **4 bundled sound packs** (all synthesized, CC0): Thock, Clicky, Tactile,
  Typewriter — switchable live from the tray or settings window
- **Mouse click sounds** (left/right/middle), separately toggleable
- Volume and random pitch-variation controls
- Optional key-release sounds
- Distinct sounds for Space / Enter / Backspace / modifiers
- Tray menu (keyboard/mouse toggles, pack picker, settings, quit)
- Config persisted to the OS config directory
- Pluggable sound-pack format (JSON manifest) — bring your own CC0 packs

## Architecture

```
src/                     Web UI (vanilla TS + Vite)
src-tauri/
  src/
    lib.rs               Tauri app: tray, window, commands, wiring
    listener.rs          Global key hook (rdev) on its own thread
    audio.rs             Audio output thread (rodio); overlapping clicks
    soundpack.rs         Pack manifest model + embedded default pack
    state.rs             Shared state; maps key events -> playback
    keymap.rs            OS key -> logical pack key name
    config.rs            Persisted settings (load/save)
  sounds/thock/          Bundled default pack (synthesized, CC0)
tools/gen_sounds.py      Regenerates the default pack (stdlib only)
```

- The keyboard listener runs on a dedicated thread because OS hooks are
  blocking. Auto-repeat is filtered by tracking held keys.
- Audio runs on its own thread because rodio's output stream is `!Send`.
  Short WAVs are decoded per-press and mixed, so overlapping keys sound fine.

## Prerequisites

- [Rust](https://www.rust-lang.org/tools/install) (stable)
- [Node.js](https://nodejs.org) + [pnpm](https://pnpm.io)
- Platform toolchains:
  - **macOS**: Xcode Command Line Tools
  - **Linux**: `webkit2gtk`, `libasound2`/ALSA dev headers, and X11 dev libs
    (e.g. Debian/Ubuntu: `libwebkit2gtk-4.1-dev build-essential libasound2-dev
    libx11-dev libxi-dev libxtst-dev`)
  - **Windows**: WebView2 (preinstalled on Win 11) + MSVC build tools

## Develop

```bash
pnpm install
pnpm tauri dev
```

## Build a release bundle

```bash
pnpm tauri build
```

Artifacts land in `src-tauri/target/release/bundle/` (`.dmg`/`.app` on macOS,
`.deb`/`.AppImage`/`.rpm` on Linux, `.msi`/`.exe` on Windows).

## Permissions

Global key capture requires OS permission:

- **macOS**: grant **Input Monitoring** (and Accessibility) to the app in
  *System Settings → Privacy & Security*. In dev, grant it to your terminal.
- **Linux**: X11 works out of the box; Wayland restricts global capture, and
  reading `/dev/input` may require the user to be in the `input` group.
- **Windows**: no extra permission needed.

## Sound packs

See [`src-tauri/sounds/README.md`](src-tauri/sounds/README.md) for the manifest
format. To regenerate all bundled packs (or one of them):

```bash
python3 tools/gen_sounds.py src-tauri/sounds            # all packs
python3 tools/gen_sounds.py src-tauri/sounds typewriter # one pack
```
